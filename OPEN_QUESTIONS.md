# Открытые вопросы

Закрытые вопросы удаляются отсюда вместе с коммитом, который их решает.

## Блокирует запуск

- [ ] **Компиляция не проверялась.** Код ни разу не проходил через MetaEditor.
- [ ] **Календарь в тестере.** `CalendarValueHistory()` в ряде сборок MT5 не отдаёт
      данные в тестере стратегий. `CNewsFilter::Init()` делает пробный запрос и пишет
      в лог предупреждение, если календарь пуст. **Проверить это до первого прогона** —
      если фильтр не работает, результаты будут завышены. Запасной путь: CSV с датами
      новостей в `Common\Files`.

## Логика

- [ ] **Диапазон для премиум/дискаунт** берётся как последний свинг-хай и последний
      свинг-лоу в истории H1. Это не обязательно одна импульсная нога — они могут
      относиться к разным движениям. Возможно, нужен явный поиск ноги.
- [ ] **Порог `InpMinRangeATR = 0.5`** — предположение, а не измерение.
- [ ] **Уровни ликвидности расходуются навсегда.** Флаг `swept` не сбрасывается, пока
      свинг не выпадет из окна истории (`InpHistoryBarsH1`). Для сильных уровней,
      которые тестируются неделями, это может быть слишком строго.
- [ ] **Позиция держится при развороте структуры** — сознательное решение, но не
      проверенное на данных.

## Реализация

- [ ] **Суммарный риск при мультивалютности.** EURUSD и XAUUSD с одним `InpRiskPercent`
      дают 1% на баланс вместо 0.5%. Нужен общий счётчик или ручное деление риска.
      Magic на каждый график должен быть разным.
- [ ] **Частичное исполнение** лимитки не обрабатывается (решено не обрабатывать).
- [ ] **Проскальзывание на пятничном закрытии** не моделируется.

## Тестирование

- [ ] **Качество истории RoboForex** по EURUSD и XAUUSD не проверялось.
- [ ] **Диапазоны оптимизации** не заданы. План: сначала пара

- [ ] **Walk-forward окна** не выбраны (кандидат: 6 месяцев обучения / 2 месяца теста).
