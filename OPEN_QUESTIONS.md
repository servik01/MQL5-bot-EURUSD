# Открытые вопросы

Закрытые вопросы удаляются отсюда вместе с коммитом, который их решает.

## Логика

- [ ] **Порог `InpMinRangeATR = 0.5`** — предположение, а не измерение. `DetectPinBar`
      теперь возвращает причину отбраковки (`range`/`tail`), EA пишет её в `SIGNAL_REJECTED`
      с фактическими `range`/`atr`/`minRange`/`tail`. После первого прогона тестера смотреть
      распределение через `awk` (как для `FILLED`/`PENDING_PLACED` в `DEVELOPMENT.md`) и
      решать, брать ли 0.5 как есть или в диапазон оптимизации.
- [ ] **Режим-зависимость: 2022-2024 — три убыточных года подряд** на EURUSD
      H4/H1 (винрейт ~18-20% каждый год против ~33-40% в 2018-2021 и 2025).
      Совпадает по времени с циклом повышения ставок ФРС — похоже на смену
      рыночного режима, а не на постепенную деградацию эджа. Фильтра волатильности/
      режима нет. Пока сознательно отложено, см. историю обсуждения.
- [ ] **Параметры не переносятся на другие пары.** Все пороги (`InpMaxEngulfBodyRatio`,
      `InpMaxEngulfRetracement`, `InpPinbarDeadZoneLow/High`, R:R, ТФ) подобраны
      вручную по EURUSD 2018-2025. На GBPUSD с теми же настройками — винрейт 20.8%,
      P&L -13.6% за тот же период (было -8.2% и до этих правок, то есть улучшения
      не перенеслись вообще). Бот де-факто EURUSD-специфичный; для других пар
      нужна отдельная калибровка, не общий набор входов.

## Реализация

- [ ] **P&L по каждому триггеру отдельно не восстановить из CSV-лога напрямую.**
      `PENDING_PLACED` пишет `setup=pinbar|engulf`, но `FILLED`/`CLOSED` тег не
      наследуют. Обходной путь уже есть: при `InpMaxPositions=1` сделки не
      перекрываются, так что `PENDING_PLACED` можно сопоставить с ближайшим
      следующим `CLOSED`/`PENDING_EXPIRED` последовательным сканированием лога —
      этим способом и считалась вся статистика по сетапам в последних анализах.
      Если понадобится с `InpMaxPositions > 1` — тогда придётся прокинуть `setup`
      в комментарий ордера/сделки (`DEAL_COMMENT`) и читать его в `OnTradeTransaction`.
- [ ] **Суммарный риск при мультивалютности.** EURUSD и XAUUSD с одним `InpRiskPercent`
      дают 1% на баланс вместо 0.5%. Нужен общий счётчик или ручное деление риска.
      Magic на каждый график должен быть разным.
- [ ] **Частичное исполнение** лимитки не обрабатывается (решено не обрабатывать).
- [ ] **Проскальзывание на пятничном закрытии** не моделируется.

## Тестирование

- [ ] **Качество истории RoboForex** по EURUSD и XAUUSD не проверялось.
- [ ] **Диапазоны оптимизации** не заданы, калибровка пока вся вручную по одному
      прогону EURUSD 2018-2025 (см. риск переобучения выше). План: сначала пара
      `InpEntryRetrace` x `InpPendingLifeBars`, затем `InpMinTailRatio` x `InpSwingBarsH1`.
- [ ] **Walk-forward окна** не выбраны (кандидат: 6 месяцев обучения / 2 месяца теста).
      Частичная проверка уже есть (EURUSD 2015-2017, не участвовал в подборе —
      результат слабее, но не отрицательный), полноценного walk-forward нет.

## Инфраструктура
