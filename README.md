# SMC PinSweep EA (MT5)

Советник для MetaTrader 5. Тренд определяется по рыночной структуре на D1 и H1,
вход — от часового пинбара, снявшего ликвидность в зоне дискаунта/премиума.

## Логика

### 1. Тренд (контекст)

Определяется независимо на **D1** и **H1** через свинг-структуру
(`SwingStructure.mqh`), которая хранит **историю** свингов за
`InpHistoryBarsD1`/`InpHistoryBarsH1` баров, а не только последний:

- Свинг-хай/лоу — фрактал с окном `N` баров слева и справа (по умолчанию 2).
  Подтверждается только после закрытия `N` баров справа.
- **BOS** (Break of Structure) — пробой последнего свинга **в сторону** текущего тренда.
- **CHoCH** (Change of Character) — пробой **против** тренда, меняет состояние.
- Пробой считается по **close** закрытого бара (`InpBreakByClose = true`).
  Это принципиально: снятие ликвидности хвостом не должно ломать структуру.
- Каждый свинг помечается `swept` при использовании как уровень входа —
  повторно тот же уровень для сигнала не берётся, пока не выпадет из окна истории.

Торговля разрешена **только при строгом совпадении** тренда D1 и H1.

### 2. Триггер входа

На последнем **закрытом** H1 баре, по порядку фильтров:

1. **Спред** — пропуск, если больше `InpMaxSpreadPoints`.
2. **Размер свечи** — диапазон бара должен быть не меньше `InpMinRangeATR * ATR(InpATRPeriod)`
   на H1 (0 отключает фильтр). Причина отбраковки (`range`/`tail`) и фактические
   числа попадают в `SIGNAL_REJECTED` в CSV-логе — по ним и калибруется порог.
3. **Пинбар** — доминирующий хвост ≥ `InpMinTailRatio` от полного диапазона свечи,
   строго больше противоположного (отсекает доджи). Направление должно совпадать с трендом.
4. **Снятие ликвидности** — хвост вышел за ближайший ещё не снятый свинг H1,
   но закрытие вернулось внутрь:
   - Покупка: `low < swingLow` **и** `close > swingLow`
   - Продажа: `high > swingHigh` **и** `close < swingHigh`
5. **Новости** (`InpUseNewsFilter`) — фиксированное дневное окно по серверному
   времени: `InpNewsHourServer:InpNewsMinuteServer` ± `InpNewsMinsBefore`/`InpNewsMinsAfter`
   (по умолчанию 14:00–15:00, сейчас сервер брокера на UTC+2). Экономический календарь
   не используется — `CalendarValueHistory()` ненадёжна в тестере стратегий.
6. **Премиум / дискаунт** (`InpUsePremiumFilter`) — откат пинбара от границы
   диапазона должен быть не меньше `InpMinRetracement`. Границы диапазона —
   одна импульсная нога: свежий экстремум по тренду (свинг-хай для BULL,
   свинг-лоу для BEAR) и ближайший противоположный экстремум перед ним по времени.

### 3. Вход и управление сделкой

Вход **лимитный**, на откате внутрь хвоста пинбара. Уровень отмеряется
от низа/верха тела вглубь хвоста:

```
Покупка:  entry = min(Open, Close) - InpEntryRetrace * lowerTail
Продажа:  entry = max(Open, Close) + InpEntryRetrace * upperTail
```

- **Стоп:** за экстремум хвоста пинбара + буфер `InpSLBufferPoints`.
- **Тейк:** фиксированный R:R (`InpRiskRewardRatio`) от лимитной цены, а не от рынка.
- **Срок жизни лимитки:** `InpPendingLifeBars` баров H1 (по умолчанию 1),
  возраст считается в барах через `iBarShift`, с учётом `SYMBOL_TRADE_FREEZE_LEVEL`.
- **Объём:** от процента риска на баланс (`InpRiskPercent`) либо фиксированный лот
  (`InpFixedLot`, если риск % = 0).
- Проверяется `SYMBOL_TRADE_STOPS_LEVEL` и то, что цена не ушла за уровень
  лимитки — иначе сигнал пропускается.
- **Выходные:** по пятницам после `InpFridayNoNewHour` новые сделки не открываются,
  после `InpFridayCloseHour` всё закрывается (`InpCloseBeforeWeekend`).

### 4. Логирование

Все сигналы, отказы и исполнения пишутся в `SMC_<символ>_<magic>.csv` в
`Common\Files` (`InpWriteCsvLog`) — общий для всех терминалов, переживает
переустановку. Формат и события описаны в `DEVELOPMENT.md`.


## Установка

Для разработки с симлинками и CLI-компиляцией — см. `DEVELOPMENT.md`.
Быстрый путь вручную:

1. В MT5: `Файл → Открыть каталог данных`.
2. Скопировать содержимое `MQL5/` поверх одноимённой папки каталога данных
   (или сделать симлинк на репозиторий — `./scripts/link-to-mt5.sh`).
3. Открыть `SMC_PinSweep_EA.mq5` в MetaEditor, `F7` — компиляция.
4. Прогнать в тестере стратегий на режиме **«Каждый тик на реальных тиках»**.

## Параметры, которые стоит подбирать первыми

| Параметр | Смысл | Комментарий |
|---|---|---|
| `InpMinTailRatio` | порог хвоста | 0.40 даёт много сигналов; попробовать 0.55–0.66 |
| `InpMinRangeATR` | мин. размах свечи в ATR | не измерено, см. `OPEN_QUESTIONS.md` |
| `InpSwingBarsH1` | размер свинга H1 | 2 = мелкая структура, 4–5 = крупная |
| `InpSwingBarsD1` | размер свинга D1 | на D1 обычно достаточно 2 |
| `InpEntryRetrace` | глубина отката в хвост | 0 = вход от тела, больше = глубже и реже налив |
| `InpPendingLifeBars` | жизнь лимитки | 1 бар даёт много пропусков, попробовать 2-3 |
| `InpMinRetracement` | мин. откат для премиум/дискаунт | 0 отключает фильтр по сути |
| `InpSLBufferPoints` | буфер стопа | зависит от инструмента и спреда |
| `InpBreakByClose` | тип пробоя | `false` резко меняет поведение структуры |

Актуальный статус открытых вопросов и решений — в `OPEN_QUESTIONS.md`.

## Известные ограничения

- Нет переноса в безубыток и трейлинга — R:R жёстко фиксирован.
- Лимитка не переставляется: если цена не дошла до уровня за отведённые
  бары, сигнал теряется целиком. Доля пропущенных входов — метрика
  для настройки `InpEntryRetrace`.
- Риск считается независимо на каждый символ/график — при нескольких
  инструментах с одним `InpRiskPercent` суммарный риск на баланс растёт
  пропорционально их числу (см. `OPEN_QUESTIONS.md`).
- Частичное исполнение лимитки не обрабатывается (сознательное решение).
- Новостное окно фиксированное и завязано на серверное время брокера —
  при смене летнего/зимнего времени сервера его нужно поправить вручную.
- Логика привязана к H1/D1 через `PERIOD_H1` / `PERIOD_D1`, а не к текущему
  таймфрейму графика: советник можно вешать на любой ТФ.
